What the desktop application does

A deliberate workflow, from edit to queue.

Local preparation

Speech recognition, candidate selection and video rendering run on the owner's computer. Source media does not need to be uploaded to this website.

Editorial review

Preview clips and their boundaries, approve content and retain a record of decisions. Automated selection remains subject to human review.

Account organisation

Keep account cards, separate browser profiles, planned assignments and activity history. Repeated assignments are checked before scheduling.

TikTok connection status

mistaste is currently a private development project. Its TikTok developer app, sandbox and Login Kit are configured for development testing. Account connection and posting have not yet been validated end to end. Public posting has not been approved.

The current browser-assisted workflow can prepare a video and caption for review. It does not automatically press Publish. A saved queue entry is not a confirmation that a video was published.

This website provides product information and policies. It has no login form, file upload, public download or live TikTok authorisation flow.

Support and data questions

Contact the project through GitHub Issues. Do not include passwords, browser cookies, access tokens or private media in public issues.
