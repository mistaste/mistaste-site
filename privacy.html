Privacy Policy

Your media stays in your workspace.

Effective date: 25 October 2026

This policy describes the current mistaste desktop development project and this information website, maintained by the GitHub account mistaste.

Information website

This website does not provide an account-registration form, collect video uploads, use advertising trackers or include third-party analytics scripts. It is hosted by GitHub Pages. GitHub processes visitor information, including IP addresses logged for security purposes, under its own Privacy Statement.

Information stored by the desktop application

The application stores source-file locations, transcripts, selected clip intervals, generated captions, rendered videos, review decisions, account labels and expected usernames, identity-check records, planned publication times and activity history on the computer where it runs.

Separate browser profiles may retain login cookies and other browser session data. The application does not ask you to send passwords or cookies to this website. Local application records are not encrypted by the application; protect the computer and its user account accordingly.

How information is used

Local records support video preparation, editorial review, account identification, duplicate-assignment checks, scheduling and troubleshooting. Current local-model processing does not require sending the source film to a cloud AI service. Installing or updating software and downloading models may contact their respective providers.

TikTok and other services

Opening TikTok in a browser, logging in or choosing to upload a video sends information directly to TikTok under its policies. This is separate from visiting this website. Official OAuth account connection is not yet implemented. If it is introduced, the app will request authorisation before accessing the account permissions presented by TikTok. This website does not currently receive OAuth tokens or host an authorisation callback.

Retention and deletion

Local records remain until you remove them. To clear an installation, close mistaste and its browser windows and remove the local application data and browser-profile directories. Transcripts and rendered clips are stored in output folders and must be removed separately if you want to delete those copies. Original videos and manually created backups remain wherever you stored them.

If you later authorise a TikTok integration, you can revoke that access through TikTok's connected-app settings. Revoking access does not delete videos already posted to TikTok; manage those through TikTok.

Support requests

GitHub Issues are public. Send only non-sensitive questions or error descriptions. Never include login credentials, session cookies, tokens or private files. The project has no support-upload service or private account-data collection form.

Changes and contact

Changes to data handling will be reflected here before the corresponding feature is offered. Questions about this policy can be raised through the project support page, without disclosing sensitive data.
